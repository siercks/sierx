## Git commits

Do not add Codex, OpenAI, ChatGPT, Claude, Anthropic, or any other AI agent as an author,
co-author, committer, or contributor to Git commits.

Do not add `Co-authored-by` or other attribution trailers for AI agents.

Preserve the human user's configured Git author and committer identity.

Do not modify `user.name` or `user.email` in Git configuration.

Before creating a commit, verify that the commit will use the user's
existing Git identity and contains no AI attribution.
