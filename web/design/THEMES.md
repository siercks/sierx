## Sierx faces, compiled from source

Built by `tools/build-font.mjs` from `fonts/source/sierx-mono.mjs`. Nothing is downloaded at any step, the faces are licensed under sierx's own Apache-2.0, and they are verified by rebuilding: a fresh compile must match the committed bytes. These are the only fonts production ships.

| File | Family | Weight | Size |
|---|---|---|---|
| fonts/sierx/sierx-mono-400.woff | Sierx Mono | 400 | 8.5 KB |
| fonts/sierx/sierx-mono-700.woff | Sierx Mono | 700 | 8.6 KB |
| fonts/sierx/sierx-symbols-400.woff | Sierx Symbols | 400 | 1.9 KB |
| fonts/sierx/sierx-symbols-700.woff | Sierx Symbols | 700 | 1.9 KB |

## Typeface policy

Third-party font binaries are excluded. Themes use operating-system font stacks and the Sierx Mono/Symbols faces compiled reproducibly from the included source. The generated font CSS references only same-origin WOFF files.
